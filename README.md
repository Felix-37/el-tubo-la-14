# El Tubo La 14

Proyecto del curso Programación 5 (grupo 6303A, UNIAJC).

Aplicación web para la Cerrajería El Tubo La 14: ventas con corte de material, retazos, caja, clientes con crédito e inventario.

## Tecnologías

- PostgreSQL
- Express
- Frontend (por definir)

## Estructura

- `database/`: scripts de la base de datos.
